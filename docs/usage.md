# 使い方ガイド（かんたん版）

DiscordのメッセージをClaude Codeに「これ見て、なんとかして」と投げられるChrome拡張の使い方です。むずかしい言葉はなるべく使わずに説明します。

---

## 1. 全体のしくみ（30秒でわかる）

```text
Discord Webのメッセージ
   ↓ 「Claude」ボタンを押す
Chrome拡張（送信画面 + Side Panel）
   ↓ HTTPで送る
Bridge（自分のPCで動く小さなサーバー）
   ↓ claudeコマンドを起動
Claude Code（いつも使っているやつ）
   ↓ 結果がリアルタイムで戻る
ChromeのSide Panelに表示
```

- **Bridge** = ChromeとClaude Codeの間に立つ通訳さん。自分のPC（または同じWi-Fi内の別PC）で動かします。
- **Side Panel** = Chromeの右側に出るパネル。Claudeの返事を読んだり、追加でお願いしたりする場所です。
- **Claude Session** = 1回の「お願い」から始まる会話のかたまり。あとから続けて指示できます。

---

## 2. 最初の準備（1回だけ）

macOS / Windows / WSL2への導入は[社内向け導入ガイド](setup.md)を参照してください。Node.js 22以上、環境に対応するClaude Code CLI、Google Chromeを使います。

初期設定が済んだら、展開フォルダで次を実行するとBridgeが起動します。

```sh
node bridge/src/index.js
```

自動起動を登録済みなら、この操作は不要です。Discord Webを開いて、次の操作へ進みます。

---

## 3. 基本の使い方：メッセージをClaudeに投げる

1. Discordでメッセージにマウスを乗せると、右上のアクション（リアクション、返信…）の横に**Claude**ボタンが出ます
2. 押すと「Claudeへ送る」画面が開きます
3. 画面の中身は次のとおりです
   - **Source Message** … 選んだメッセージのプレビュー
   - **Message Context** … 一緒に送るメッセージの一覧。チェックでON/OFFでき、「前5件を追加」「後5件を追加」で周りの会話も足せます
   - **Action Preset** … やってほしいことのテンプレ（Jiraに起票 / GitHub Issue化 / 要約 / 調査 / 批評 / 自由入力）
   - **作業先** … ふつうは「一般」のままにします。コードを直してほしいときだけ「Projectを選択」でリポジトリを選びます
   - **追加指示** … 自由に書く欄。Presetと組み合わせてもいいし、自由入力だけでもかまいません
4. 「Claudeへ送信」を押すと、右にSide Panelが開いてClaudeの返事が流れてきます
5. 終わったら「最終回答をコピー」でクリップボードへコピーできます

### 返信メッセージを選んだとき

返信（リプライ）を選んだ場合は、**返信元をたどった会話と、そのメッセージへの返信**が自動でまとめて選ばれます。関係ない枝分かれは入りません。20件を超えると「多いよ」と注意が出ますが、そのまま送れます。

### 添付ファイル

画像・PDF・テキスト・ソースコード・JSON・ログなどは、Bridgeが自動でダウンロードしてClaudeが読めるようにします（24時間で自動削除）。動画や音声は大きいのでダウンロードせず、ファイル名とURLだけをClaudeに伝えます。

---

## 4. Side Panelでできること

Side Panelの上半分はセッション一覧、下半分がいま開いているセッションです。

| ボタン / 欄 | なにが起きる |
|---|---|
| **追加指示** → 送信 | 同じClaude Sessionに続けてお願いできます（「この内容でJiraに起票して」など） |
| **停止** | 実行中の処理だけ止めます。セッションは残るので、また指示できます |
| **最終回答をコピー** | Claudeの最後の返事をコピーします |
| **Discordコンテキストを更新** | Discord側で会話が進んだとき、**まだ送っていないメッセージだけ**を一覧で見せてくれます。チェックして「Current Sessionに追加」を押すと同じセッションに足せます。自動で取り込むことはありません |
| **Projectで続行 (Handoff)** | 「一般」で調査していた内容を、リポジトリでの実装作業に切り替えるときに使います（次の章） |
| **ターミナルで開く** | 同じPCでBridgeが動いていれば、Terminal.appが開いて同じセッションを`claude --resume`で続けられます |
| **resumeコマンドをコピー** | Bridgeが別PCにあるとき用です。`cd "<フォルダ>" && claude --resume <id>`をコピーして、そのPCで貼り付けて実行します |

拡張アイコンの赤いバッジは「終わったけどまだ見ていないセッションの数」です。開けば消えます。

### Discordを「アプリとしてインストール」して使っている場合

Chromeのメニュー（⋮）→「保存して共有」→「ページをアプリとしてインストール」でDiscordを独立ウィンドウにしている場合、そのウィンドウにはSide Panelがありません。代わりに、同じ内容の**別ウィンドウ**がDiscordウィンドウの右端に開きます。2回目以降は同じウィンドウを前に出すだけです。操作はMac・Windowsどちらも同じですが、拡張アイコンのバッジはアプリのウィンドウには表示されません。

### セッション一覧のルール

- 一覧はChrome側に「目次」を持っているだけで、本体はClaude Codeのセッションです
- Side Panelを開くたびにClaude Code側を確認し、消えていたセッションは一覧からも自動で消えます
- 削除ボタンやアーカイブはありません（Claude Codeの保存期間にそのまま従います）

## 5. 調査 → 実装に進みたいとき（Handoff）

「一般」で調査してもらい、「よし、これ直そう」となったら次の手順です。

1. Side Panelで「Projectで続行 (Handoff)」を開く
2. リポジトリを選ぶ（必要なら追加指示も書く）
3. 「Handoffを生成してProject Sessionを開始」を押す

するとClaudeが元の会話から**引き継ぎメモ**（調査結果 / 決定事項 / Discordのリンク / 関連リンク / 今わかっている問題 / 次にやること）を作り、それを最初の指示にして、選んだリポジトリで**新しいセッション**が始まります。

- 元の調査セッションはそのまま残ります（書き換えません）
- 新しいセッションには「元セッション: ○○」リンクが表示されるので、いつでも戻れます

---

## 6. 別のメッセージを今のセッションに足したいとき

Side Panelでセッションを開いたまま、Discordの別のメッセージで**Claude**ボタンを押すと、送信画面の上に次の選択肢が出ます。

```text
(•) 新しいセッションを開始   ( ) 現在のセッションに追加: ○○
```

「現在のセッションに追加」を選ぶと、そのメッセージ（と選んだ周辺の会話）が今のセッションに追記されます。ふつうは「新しいセッションを開始」のままでOKです。

## 7. うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 「Claude Bridgeに接続できません」 | Bridgeのターミナルが動いているか確認します。拡張のオプション画面で「接続テスト」も試せます |
| Claudeボタンが出ない | Discord Webをリロードします。拡張を再読み込みしたあとも、Discordのリロードが必要です |
| Side Panelが開かない | Discordを「アプリとしてインストール」したウィンドウで使っていると、Side Panelではなく別ウィンドウで開きます。他のウィンドウの後ろに隠れていないか確認してください |
| 「Discordコンテキストを更新」で「チャンネルを開きました。もう一度押してください」 | Discordタブが別のチャンネルにいたので移動しただけです。読み込みが終わったらもう一度押せばOKです |
| 「ターミナルで開く」が出ない | Bridgeが別PCで動いているか、`terminalCommand`が空です。「resumeコマンドをコピー」を使ってください |
| 「〇〇の実行権限が許可されていない」と返ってくる | 非対話モードでは許可ダイアログを出せないためです。`workspace`フォルダの`.claude/settings.json`に`"permissions": { "allow": ["mcp__claude_ai_Atlassian", "Bash(gh issue create:*)"] }`のように事前許可を書きます（[設定リファレンス](reference.md)の「非対話モードのツール許可」参照） |
| Claude側でエラー | Side Panelにエラー文が出て、その実行は終わります。同じセッションに追加指示すれば続けられます（自動リトライはしません） |

---

## 8. 覚えておくと便利なこと

- Claudeの権限（ファイル編集、git、MCPなど）は、**いつも使っているClaude Codeの設定がそのまま**使われます。拡張が勝手にゆるめたり厳しくしたりはしません
- `workspace`フォルダに`CLAUDE.md`やMCP設定を置くと、「一般」のお願いのときにそれが効きます（JiraやGitHubのMCPはここに置くのがおすすめです）
- Action Presetを増やしたいときは、`bridge/config.json`の`actions`に`{ "id", "label", "prompt" }`を足してBridgeを再起動するだけです。拡張側の変更は不要です
- Bridgeには認証がありません。使わないときは止めておきましょう
